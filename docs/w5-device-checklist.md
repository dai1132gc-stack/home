# W5 小程序真机与合法域名准备清单

> 更新时间：2026-11-08  
> 适用范围：`home/client` 原生小程序（Skyline）+ `realestate-server` 本地/体验环境  
> 结论先行：**自动化只能验证页面逻辑与后端接口；微信授权弹窗、code2session 真实换取、真机网络与合法域名必须由用户扫码验证。** 本清单中标注“待用户验证”的项不得视为已通过。

## 1. 当前状态与阻塞项

| 项 | 当前值 | 状态 |
|---|---|---|
| 小程序 AppID | `project.config.json` 中为测试号 `wx0ebf901e27616902` | 已有，可用于开发者工具与体验版 |

真实微信登录放行条件（全部满足）：

1. 微信公众平台 → 开发管理 → 开发设置，取得正式 AppID 与 AppSecret；
2. AppSecret 只写入 `realestate-server/.env` 的 `WECHAT_MINI_APP_SECRET`，**不得写入小程序、前端或 Git**；
3. `WECHAT_MINI_APP_ID` 与小程序 `project.config.json` 的 AppID 一致；
4. 重启后端，`POST /api/v1/auth/wechat-login` 不再返回 503；
5. 开发者工具与真机使用同一后端环境，且该环境可被手机访问（HTTPS 域名）。

## 2. AppID / AppSecret 配置步骤

### 2.1 后端

```bash
# realestate-server/.env（不提交 Git，不在终端回显）
WECHAT_MINI_APP_ID=<正式 AppID>
WECHAT_MINI_APP_SECRET=<正式 AppSecret>
WECHAT_MINI_TIMEOUT_SECONDS=4
```

- 修改后重启后端；未配置时接口按设计返回 `503 AUTH_50301`，不会伪造登录成功。
- 校验方式（不打印密钥）：`curl -s -o /dev/null -w '%{http_code}' -X POST http://localhost:8080/api/v1/auth/wechat-login -H 'Content-Type: application/json' -d '{"code":"invalid","clientType":"MINI"}'`。配置正确时应为 `401`（code 无效），而不是 `503`。

### 2.2 小程序

- `project.config.json` 的 `appid` 必须与后端 AppID 一致；切换正式 AppID 后重新打开工程并编译。
- 不在 `client/config/env.js`、`app.js` 或任何页面中出现 AppSecret。
- 登录页“微信一键登录”失败时会明确提示“微信登录未配置，请使用账号密码”，不做静默降级。

## 3. 合法域名（微信公众平台 → 开发管理 → 开发设置 → 服务器域名）

| 类型 | 配置项 | 要求 | 本机示例（仅说明格式） |
|---|---|---|---|
| request 合法域名 | API 域名 | HTTPS、已备案（ICP）、不能带端口、不能为 IP、不能为 localhost | `https://api.example.com` |
| uploadFile 合法域名 | 报修图片上传 | 同上；必须与 API 同域或用独立上传域名 | `https://api.example.com` |
| downloadFile 合法域名 | 合同 PDF、私有图片 | 同上；PDF 与图片均走鉴权下载 | `https://api.example.com` |
| socket 合法域名 | 本项目不使用 | 留空 | — |

说明：

1. `http://localhost:8080` 只能用于开发者工具“不校验合法域名”模式，**真机与体验版不可用**。
2. 生产必须 HTTPS；证书需被微信客户端信任，不能使用自签名证书。
3. 后端 `CORS_ALLOWED_ORIGINS` 只影响浏览器，小程序不受 CORS 限制，但合法域名仍必须在公众平台配置。
4. 若 API 部署在子路径（如 `/api`），合法域名只填域名，不带路径。
5. 修改域名后需在开发者工具“重新编译”，必要时清除缓存；体验版需重新上传。

## 4. 隐私声明与权限

微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引，至少声明：

| 信息/权限 | 用途 | 触发点 |
|---|---|---|
| 微信登录标识（openid） | 识别客户身份、免密码登录 | 点击“微信一键登录” |
| 相册/相机 | 上传报修现场图片 | 报修提交页“添加图片” |
| 手机号（用户手动填写） | 预约看房、报修联系 | 预约/报修表单，非微信手机号授权 |
| 设备与网络信息 | 保障接口安全与故障排查 | 所有请求（服务端日志仅记录 traceId） |

本项目**不获取**微信手机号、不读取通讯录、不采集定位、不做支付。隐私指引未配置时，体验版可能无法通过审核。

## 5. 真机预览步骤（必须由用户执行）

1. 确认后端可从手机访问：手机浏览器打开 `https://<API 域名>/actuator/health`，应返回 `{"status":"UP"}`。
2. 微信开发者工具打开 `D:/graduate/home/client`，确认 AppID、`config/env.js` 的 `apiBaseUrl` 指向 HTTPS 域名。
3. 点击“预览”，生成二维码；**由用户使用本人微信扫码**，不要使用他人账号或截图代替。
4. 首次进入点击“微信一键登录”，确认出现微信授权弹窗；同意后应进入首页并显示昵称（“微信用户+随机后缀”）。
5. 若后端未配置凭据，应提示“微信登录未配置，请使用账号密码”，不得出现“登录成功”假象。
6. 依次执行第 6 节用例，记录实际结果与截图；失败时保留 traceId。

## 7. 常见失败与排查

| 现象 | 排查 |
|---|---|
| 微信登录提示“未配置” | 后端 `.env` 是否配置 AppID/AppSecret；是否重启；是否为空字符串 |
| 微信登录 401 `AUTH_40105` | code 已使用或过期（一次性）；检查是否重复提交同一 code；重新点击登录 |
| 微信登录 502 `AUTH_50201` | 手机/服务器到 `api.weixin.qq.com` 网络、DNS、超时；稍后重试，不无限重试 |
| 真机提示域名不合法 | 公众平台 request/uploadFile/downloadFile 是否配置；是否 HTTPS/备案/带端口 |
| 真机请求超时、开发者工具正常 | 手机与后端网络是否互通；`apiBaseUrl` 是否 `localhost`；防火墙/安全组 |
| 上传 401 | 上传是否显式带 `Authorization`；Access Token 是否过期（应自动刷新重试一次） |
| PDF 打不开 | 下载接口是否 200；`openDocument` 是否支持 PDF；文件是否为中文 PDF |
| 登录后返回不到原页面 | 页面栈是否被 `reLaunch` 清空；从首页进入的页面应可 `navigateBack` |

## 8. 验收边界声明

- 本文档中的“已自动验证”仅代表 `docs/mini-w5-flow.mjs` 与后端单测在**本机 Node 模拟 + 真实后端接口**下通过。
- 微信授权弹窗、jscode2session 真实换取、真机网络、合法域名、相册/相机权限、PDF 真机打开均**未验证**，必须由用户扫码完成。
- 未配置正式 AppID/AppSecret 前，不得在论文或答辩中声称“微信登录已联调通过”，应表述为“微信登录后端与降级路径已实现，真实 code2session 待正式凭据”。
